# 🧅 RZMPS

Compose Three.js particle effects from emitters, modules, renderers, and scene spatial effects.
A particle system is an Object3D: attach it to a scene, update it, and render with your existing camera.

- [Getting Started](guides/first-particle-system.md): install the package and render an effect.
- [Guides](guides/index.md): follow the tutorials, learn the core concepts, and explore individual features.
- [API Reference](api/index.md): declarations and source-level documentation.
- [Examples](examples/index.md): configuration explanations linked to canonical source.
- [Feature Guides](guides/index.md#feature-guides): tags, subsystems, collision, and particle octrees.
- [AI Coding Assistants](guides/ai-coding-assistants.md): explicit skill installation and version-aware guidance.
- [Deployment](guides/deployment.md): one Render deployment for the demo and docs.
- [Contributing](contributing.md): examples, documentation, and visual validation.
