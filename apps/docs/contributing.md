# Contributing

To add or improve an effect, start with [Writing Example Guides](https://github.com/rzmay/rzmps/blob/HEAD/apps/docs/README.md#writing-example-guides).
It explains how to turn a visual intention into a readable preset and a walkthrough someone else can follow.
The [shared examples README](https://github.com/rzmay/rzmps/blob/HEAD/examples/README.md) describes factory metadata,
source regions, assets and scene ownership.

For repository setup, API conventions, tests and PR preparation, see
[CONTRIBUTING](https://github.com/rzmay/rzmps/blob/HEAD/CONTRIBUTING.md).
The [documentation workspace README](https://github.com/rzmay/rzmps/blob/HEAD/apps/docs/README.md)
covers generation, previews, search/SEO and generated-file policy.

Keep example explanations focused on building and adapting an effect. Put benchmark measurements,
backend investigations and development findings in the relevant tooling documentation or PR discussion.
