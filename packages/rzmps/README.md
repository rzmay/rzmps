# 🧅 RZMPS

A modular Three.js particle system. Compose emitters, lifetime modules, spatial effects,
renderers, and event-triggered subsystems with CPU or GPU simulation.

```bash
npm install @rzmps/rzmps three three-mesh-bvh
```

- [Getting started](https://rzmps.rzmay.com/docs/guides/first-particle-system.html)
- [Guides](https://rzmps.rzmay.com/docs/guides/concepts.html)
- [GPU processing and extension development](https://rzmps.rzmay.com/docs/guides/gpu-processing.html)
- [Generated API reference](https://rzmps.rzmay.com/docs/api/)
- [Example explanations](https://rzmps.rzmay.com/docs/examples/)
- [Interactive demo](https://rzmps.rzmay.com/)
- [Contributing](../../CONTRIBUTING.md)

API reference pages are generated from the public TypeScript source. The canonical
human documentation is maintained under `apps/docs`; example implementations live in `examples`.

## AI Coding Assistants

The optional [RZMPS skill](https://github.com/rzmay/rzmps/tree/HEAD/.agents/skills/rzmps)
helps coding assistants build Three.js particle systems and VFX using emitters, modules,
renderers, and WebGL/WebGPU previews.

```bash
npx skills add rzmay/rzmps --skill rzmps
```

Review the skill and authorize installation before changing agent configuration.
The npm package includes a short generated `AGENTS.md`, without bundling the full skill or
its references. These entry points do not guarantee automatic agent discovery. For the
installed version's API, inspect `build/index.d.ts` and the package version; see the
[canonical documentation](https://rzmps.rzmay.com/docs/) for guides.
